AI-Driven Investment System

  • Python
  • Streamlit
  • Factor models
  • Web crawling
  • Active ETF analysis

Can we separate what a manager intends from what the market simply does to their portfolio?

A single dashboard that moves from macro trends to single-stock alpha to competitor behavior. It strips market, sector, size, value and momentum effects out of earnings-day returns with a 5-factor regression to isolate the residual, and it tracks top active-ETF managers daily, separating deliberate rebalancing (intent) from passive price drift.
